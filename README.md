# Jadyx para Xbox



O Jadyx é um emulador de Nintendo Switch; este repositório reúne builds experimentais para Xbox Series X|S em Modo de Desenvolvedor. As versões aqui testam FSR 1 junto com geração de quadros e saída na resolução da TV, além de pequenos ajustes no caminho gráfico D3D12.



Os resultados variam conforme o jogo, e as mudanças de desempenho ainda precisam ser testadas no console. Os AppX são builds de teste, assinados com certificado temporário, não versões oficiais do mantenedor. Cada download traz os arquivos necessários para instalação. Não são incluídos jogos, firmware ou chaves.
